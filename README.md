## 🧪 What I'm working on

### 🌫️ VapourArch
A custom Arch + GNOME live USB built with `archiso`. It boots straight off the drive, has a dark/orange theme, and includes a companion app that clones the running system onto a new stick.
`Arch Linux` · `archiso` · `GNOME` · `Bash`

### 🎨 Chroma
An Android daily challenge: find something in the real world, photograph it, and see how close you got to the target colour. Scoring uses perceptual Delta E distance in CIELAB, not naive RGB.
`Kotlin` · `Jetpack Compose` · `CameraX`

### 🎵 MP3LOADER
A single static Go binary with a browser-based UI. Import a playlist CSV and it downloads each track as 320 kbps MP3 with full metadata and cover art. It fetches its own dependencies and cleans up after itself.
`Go` · `yt-dlp` · `ffmpeg`

### 🖼️ [Pixel Diary](https://github.com/fordpepper/pixeldiary)
A pixel-art mood tracker on a pixel-exact 98×49 canvas, with local plain-text storage and zero pip installs. GitHub Actions builds the cross-platform executables.
`Python` · `tkinter` · `GitHub Actions`

## 🧭 How I like to build

- **Self-contained over sprawling:** one binary, no installs, no surprises
- **Test on real hardware:** most of my bugs only show up there
- **Look matters:** if it's mine, it has a visual identity
- **Learn by shipping:** every project is a new stack I didn't know the week before
